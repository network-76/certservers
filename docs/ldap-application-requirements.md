# LDAP 对接与证书申请审批需求

## 1. 目标

对接组织现有 LDAP 目录，完成申请人身份验证、目录属性读取、领域授权和证书申请审批。LDAP 认证成功仅证明凭据有效，不自动授予证书申请资格或签发权限。

本文件定义需求；具体流程与安全设计见《LDAP 身份验证与证书申请审核设计》（`docs/ldap-integration.md`）。

## 2. LDAP 对接需求

- 支持 LDAPS（默认端口 636）及 LDAP + StartTLS（默认端口 389）；明文 LDAP 默认禁用，不得通过未加密连接发送密码。
- 必须校验 LDAP 服务端证书及信任链。支持配置 LDAP 根/中间 CA 证书，显示证书来源、有效期和校验状态。
- 支持配置服务器地址、连接/读写超时、主备服务器、服务绑定 DN、用户搜索 Base DN、过滤器、登录名属性、稳定唯一标识属性、账号状态属性及组关系映射。
- 服务绑定账号仅授予读取必要用户属性和组关系的最小权限；绑定凭据使用受保护的秘密配置，不写入仓库示例或日志。
- 用户密码仅用于对用户 DN 执行 LDAP Bind 验证，不读取密码哈希、不在本平台保存用户密码。
- 属性映射应适配不同 LDAP Schema；优先用 entryUUID、objectGUID 等稳定标识关联目录对象，不只依赖登录名。
- LDAP 搜索过滤器必须对用户输入执行 RFC 4515 转义，防止 LDAP 注入。

## 3. 证书申请与审批需求

- 申请人完成 LDAP 身份验证后，平台读取策略允许的属性和组信息，并按证书领域模板自动填充申请字段。
- 模板可配置允许申请的 LDAP 用户组/组织范围、字段来源与可编辑性、证书用途、有效期、算法、密钥生成模式和审批策略。
- 自动签发必须同时满足：身份验证成功、账号启用、领域授权通过、申请字段符合模板、CSR 签名及算法有效、证书用途和有效期符合策略，且无风险标记。
- 以下情况应转人工审核或按策略拒绝：自定义主体/SAN、超范围用途或有效期、平台生成私钥/P12 导出、特殊设备/敏感领域、组关系不明确或双人审批要求。
- 身份验证失败、账号禁用、无领域权限、CSR 无效、违反强制策略等硬失败必须拒绝；人工审批不得绕过硬校验。
- LDAP 暂时不可用、服务端证书校验失败或账号状态无法确认时，不得自动签发。可拒绝或进入待处理状态，恢复后重新核验。
- 支持人工审核队列、审核意见、审批人/时间、退回补充材料、拒绝及可配置双人审批。
- 审批和签发必须使用申请提交时绑定的模板及策略版本；模板发布后不可变更历史申请的审批依据。

## 4. 目录同步与账号变更

- 支持启动时目录为空则全量拉取；已有数据时按变更标识增量同步。
- 支持目录侧推送变更并由平台确认接收，另提供定期对账以发现遗漏。
- 账号禁用、离职或移出授权组后，阻止新申请；是否自动吊销已签发证书由组织策略明确配置并审计。
- 如需实时断开已建立的 RADIUS 会话，应由 RADIUS 协作实现 Disconnect/CoA（RFC 5176）；证书吊销、会话断开是不同动作，不得混为一谈。
- LDAP 属性变化不得静默修改已签发证书；更新证书应发起新的申请和签发流程。

## 5. 审计与隐私

记录目录身份标识、必要属性快照、认证结果、模板/策略版本、字段来源与修改差异、审批结果、证书序列号及签发/吊销结果。不得记录用户密码、服务绑定密码、私钥或 P12 导出密码。属性快照应遵循最小化和保留期限要求。

## 6. 验收标准

- LDAPS、StartTLS 的连接、服务端证书校验及错误处理通过测试。
- 正确区分认证失败、账号禁用、无组授权、目录不可用和属性缺失。
- 验证 LDAP 注入防护、凭据不落日志/数据库及最小权限。
- 验证自动签发、人工审核、拒绝和 LDAP 故障时禁止自动签发的完整流程。
- 验证账号禁用/组变更后的新申请限制、证书吊销策略及 RADIUS 会话联动边界。
