# Web 导航与功能模块基线

- 文档编号：PROD-NAV-001
- 状态：导航主菜单已确认；子菜单为候选草案，须经需求核对
- 适用范围：Web 导航、产品功能模块、功能文档目录

## 1. 导航原则

1. Web 主菜单作为产品功能划分的一级入口，子菜单作为二级功能入口。
2. 功能文档按导航归档；总体架构、全局安全、运维、测试规范和技术决策等跨功能资料单独归档。
3. 菜单名称可调整，文档编号应稳定；不得仅因菜单改名而重编号。
4. “候选”或“待确认”功能不视为已批准需求，不据此承诺首期交付。
5. 密码服务底层可使用纯软件或 SDF 硬件实现；业务操作与业务接口保持一致，资源配置和运维信息由授权管理员管理。

## 4. 首期范围约束

已明确纳入首期完整实现的事项：
- OCSP；
- 设备证书及其资产授权、申请和生命周期闭环；
- SDF 硬件密码设备对接；
- 密码服务同时支持纯软件和硬件实现，业务操作统一；
- 安全审计主菜单及审计日志、审计归档入口。

“完整实现”应以可部署配置、端到端流程和可验收结果为准；接口占位或模拟实现不能作为交付完成。SDF 最终硬件验收须使用实际目标设备及厂商组件。

## 5. 待确认事项

- 监控中心展示哪些指标、告警、待办，以及是否包含告警规则配置。
- 身份与资产中组织、用户、设备、LDAP 的具体菜单层级。
- 证书业务与 CA 管理的操作边界、敏感操作审批及角色权限。
- 密码资源、密钥管理的具体管理能力；目标 SDF 设备型号、厂商库及能力范围。
- 状态服务中 OCSP 的访问控制、缓存、超时和故障策略。
- 审计归档的格式、完整性验证、保留期限、检索和导出要求。
- 系统管理是否包含告警配置、升级、任务调度等功能。

## 6. 维护规则

菜单新增、合并、改名或调整层级时，先更新本基线及映射表，再同步 Web 导航、权限矩阵和文档索引。未经需求确认，不将候选子菜单标为已批准功能。
