# LDAP 身份目录适配模块

本模块封装标准 LDAP 目录服务器的连接和身份验证能力，为证书申请流程提供可信的目录身份信息。

## 主要职责
- 建立 LDAPS 或 LDAP + StartTLS 加密连接，并验证目录服务器证书。
- 使用受限服务绑定账号搜索用户条目和读取允许访问的目录属性。
- 使用用户 DN 执行 LDAP Bind 验证申请人凭据。
- 读取账号启用状态、稳定唯一标识和策略所需的组成员关系。
- 将 LDAP 产品差异、属性名称和组关系规则封装为可配置映射。
- 对搜索过滤器执行 RFC 4515 转义，防止 LDAP 注入。
- 对连接超时、服务不可用、账号禁用和属性缺失返回明确错误，不得在无法验证身份时默认放行。

## 安全约束
- 不保存用户 LDAP 密码，不读取或比较 LDAP 密码哈希。
- 服务绑定凭据存放在受限秘密配置中，不提交到代码仓库。
- 只读取证书申请所需的最少目录属性。
- 优先使用 entryUUID、objectGUID 等稳定标识关联用户。
- LDAP 身份验证通过不代表证书申请自动获批；签发授权由申请策略模块独立判断。
