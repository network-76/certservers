# 数字证书管理模块

本模块负责证书申请、校验、签发、查询、吊销和导出。

## 主要职责
- 接收 PKCS#10 CSR（证书签名请求），解析申请者公钥和主体信息。
- 验证 CSR 自签名，拒绝签名无效或不符合策略的申请。
- 按证书模板校验主体名称、SAN（主题备用名称）、密钥用途和 EKU（扩展密钥用途）。
- 生成符合 X.509 v3 标准的证书。
- 管理证书序列号、签发者、有效期和状态。
- 支持 PEM、DER 和 P12/PKCS#12 格式的证书交付与导出。
- 对 PEM 导出明确证书、证书链和私钥文件的边界；对含私钥的 P12 导出执行强身份认证、权限检查、独立密码保护和审计。
- 执行证书吊销并向 CA 模块提供 CRL 生成所需信息。

## 密钥归属约束

CSR 模式下，申请者私钥由申请者自行生成和保管，平台只接收公钥及签名请求，不能导出该私钥对应的 P12。若需要含私钥的 P12，必须使用平台生成密钥的可选流程，且必须明确告知密钥曾由平台生成或处理。

所有证书字段必须经过策略校验，不能直接信任客户端提交的内容。


## 领域模板与审批协作

证书申请模块必须使用申请记录绑定的领域模板版本进行服务端校验。模板可以从 LDAP 目录属性自动填充字段，也可以要求用户填写或选择字段。模块应保留字段来源、自动填充值、用户修改值和最终签发值，以支持审批和审计。

证书签发前必须取得申请策略模块的明确决策：自动签发、人工审批通过或拒绝。LDAP 身份验证成功本身不是签发授权。
