# 开发路线图

## 阶段 0：基础工程
- [x] 确定初步技术选型和仓库目录结构。
- [x] 建立中文需求、架构、安全和术语文档。
- [ ] 明确 API 约定、数据库迁移规范和威胁模型。
- [ ] 建立持续集成构建、静态分析和基础测试。

## 阶段 1：CA 基础能力
- [ ] 完成密码引擎选型验证，优先评估铜锁（Tongsuo）。
- [ ] 实现 CA 密钥及 CA 证书生命周期管理。
- [ ] 实现 CSR（证书签名请求）解析、签名验证和严格的证书模板校验。
- [ ] 实现 SM2 密钥生成、证书签发和签名验证测试。
- [ ] 验证 X.509 v3 证书扩展字段和证书链。
- [ ] 实现 PEM、DER 格式的证书导出和解析。

## 阶段 2：证书生命周期与交付管理
- [ ] 实现证书查询、筛选、下载和导出。
- [ ] 实现 PEM 格式证书、证书链及受控私钥导出。
- [ ] 实现 P12/PKCS#12 文件创建、密码保护、证书链封装和导入验证。
- [ ] 实现平台生成终端密钥的可选流程，并对私钥导出实施强权限控制和审计。
- [ ] 实现证书吊销、原因记录和审计。
- [ ] 实现 CRL（证书吊销列表）生成、签名、发布和自动更新。
- [ ] 实现管理员角色权限控制。

## 阶段 3：Web 与 API
- [ ] 实现管理员认证和会话管理。
- [ ] 实现版本化 API 和管理界面。
- [ ] 完成 MariaDB 数据迁移和备份恢复机制。
- [ ] 加固 Nginx、Unix 域套接字和 systemd 部署配置。

## 阶段 4：RADIUS 互通性
- [ ] 验证目标终端 supplicant（802.1X 认证客户端）与证书配置。
- [ ] 验证 RADIUS 的 EAP-TLS 后端及 TLS 密码库组合。
- [ ] 验证 PEM/P12 格式的 SM2 证书及密钥在目标终端的导入兼容性。
- [ ] 验证证书链、算法协商和吊销检查。
- [ ] 实现并测试 CRL 自动获取、缓存、过期告警和异常处理。
- [ ] 评估 OCSP（在线证书状态协议）及 HSM/SDF/SKF 密码设备集成。


## 阶段 3A：领域模板与申请表单

- [ ] 建立领域模板数据模型及版本管理。
- [ ] 预置 Wi-Fi、员工、网络设备、服务器等领域模板。
- [ ] 实现字段来源、默认值、必填/选填、只读/可编辑和覆盖规则。
- [ ] 实现 Subject、SAN、Key Usage、EKU、有效期、CA 和交付格式的模板映射。
- [ ] 实现申请页面按领域模板动态生成表单。
- [ ] 实现服务端模板版本校验和字段差异审计。

## 阶段 3B：LDAP 身份验证与审批

- [ ] 实现标准 LDAP 连接适配，支持 LDAPS 和 StartTLS。
- [ ] 实现服务绑定、用户搜索、用户 Bind 验证及目录属性读取。
- [ ] 实现 LDAP 属性映射、稳定用户标识关联和组成员关系判断。
- [ ] 实现领域申请资格策略和自动签发/人工审核/拒绝决策。
- [ ] 实现人工审核工作台、审批意见和双人审批策略。
- [ ] 实现 LDAP 故障、账号禁用、组变更和属性变化处理。
- [ ] 完成 LDAP 注入防护、访问限速、审计和安全测试。
